# TELECOM-NET-SIM

**Fully local mobile network simulator (2G-6G) with OSINT/SIGINT analytics, attack simulation, and three Streamlit dashboards.**

[![CI](https://github.com/hosras/MNO-simulator/actions/workflows/ci.yml/badge.svg)](https://github.com/hosras/MNO-simulator/actions/workflows/ci.yml)
[![Coverage](https://raw.githubusercontent.com/hosras/MNO-simulator/main/.github/coverage.svg)](https://github.com/hosras/MNO-simulator)

## What is it?

A comprehensive, **offline-only** mobile network simulator that covers:

- **Simulation**: 2G / 3G / 4G / 5G / 6G topology, subscribers, CDRs, voice bearers, messaging
- **Analysis**: OSINT (public registry, complaints), SIGINT (IMEI churn, SIM-box, impossible-travel)
- **Attack simulator**: 24 attack types across SS7 / Diameter / GTP / PFCP / SIP / O-RAN / 6G
- **Dashboards**: 3 Streamlit apps (operations, analytics, admin)

## Security Posture

- **Zero external network calls** (static scan verified)
- Streamlit telemetry **disabled**
- Dashboards bind to **127.0.0.1 only**
- Password hashing with **scrypt** (n=2^14)
- SQLite WAL + online backup API

## Quick Start

```bash
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt

python telecom_net_sim.py
streamlit run telecom_dashboard.py
```
